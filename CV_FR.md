## Projets Informatiques
*Consultables sur mon profil GitHub.*
- **[Automate cellulaire (feu de forêts)](https://github.com/AngeleKowalik/forest_fire_model)** : Un modèle de feu de forêts recréé d'après l'article de Drossel et Schwabl. L'automate est conçu via une matrice 2D NumPy. Chaque calcul est réalisé au moyen de masques booléens ou des méthodes vectorielles de NumPy pour utiliser au maximum l'optimisation apportée par C.
- **[job-finder-CLI](https://github.com/AngeleKowalik/job-finder-CLI) :** Outil en ligne de commande en Python qui interagit avec l'API `recherche-entreprise.gov`. Filtre les entreprises, gère la pagination des résultats et prend en charge les erreurs réseau (timeout, erreurs HTTP) pour éviter les crashs.
- **[python-toolkit](https://github.com/AngeleKowalik/python-toolkit) :** Modules et fonctions utilitaires créés pour éviter de dupliquer du code entre mes différents projets. Ce package est modulaire avec la possibilité de faire des imports sélectifs. Chaque fonction est accompagnée d'une docstring, de type hinting et d'un test Pytest (en cours d'intégration).
